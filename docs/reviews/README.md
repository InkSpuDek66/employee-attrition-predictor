## อ่านอย่างไร

- เลข ID ใช้ต่อกันทุกรอบ (เช่น SEC-14 เริ่มที่รอบ 3) สถานะล่าสุดของแต่ละ ID ดูในรายงานรอบล่าสุด
- checkbox ของงานแต่ละคนอยู่ในรายงานรอบที่ตั้ง ID นั้น แก้เสร็จแล้วติ๊กพร้อมใส่ commit hash
- ไม่เห็นด้วยกับข้อไหน เขียนในหัวข้อ "ความเห็นทีม" ของรายงานรอบนั้น
